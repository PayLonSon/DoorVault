# 三扇門｜惡夢

一款 5 到 10 分鐘就能玩完的網頁恐怖遊戲。每次入睡都是新的一局，不存檔。

**流程**：入睡 → 床邊三樣道具選一樣 → 選一扇門 → 在惡夢裡達成醒來條件 → 結算時揭曉每樣道具對這個惡夢的效果（有效／無效／反效果）。

目前內容：5 個成語故事、6 種道具。每局從五扇門中抽三扇。

| 門 | 機制 | 醒來條件 | 有效／無效／反效果 |
|---|---|---|---|
| 飛蛾撲火 | 繞著燈飛，會被光吸引 | 關上 4 扇窗 | 聲音、煙／鹽、符／光 |
| 杯弓蛇影 | 你移動時牠不動，停下來牠才靠近 | 打翻 5 隻酒杯 | 光、鏡／煙、火、聲音／符 |
| 守口如瓶 | 看不見，只聽聲音；跑步很吵、慢走很安靜 | 撿回 4 把鑰匙 | 煙、符／光、鏡／聲音 |
| 如影隨形 | 影子一步不差地走你走過的路，停太久會被追上 | 點亮 4 根蠟燭 | 鹽、符／聲音、煙／光、鏡 |
| 請君入甕 | 五個甕裡藏著一個，碰到就破甕而出 | 封住 4 個甕（可以避開會敲的那個） | 火／符、光、鏡／鹽 |

五張地圖都依故事設計，形狀和大小各不相同：

- **飛蛾撲火**：奶奶的閣樓，有床、搖椅、衣櫃，燈泡吊在正中央。
- **杯弓蛇影**：除夕的宴客廳，一張長桌，北牆掛著一把弓，蛇從弓的影子裡出來。
- **守口如瓶**：夜裡的家，從自己的房間出發，穿過走廊，到大人低聲說話的客廳。
- **如影隨形**：醫院的長廊，從中間出發，兩頭都要去；回頭不換路就會撞上自己的影子。
- **請君入甕**：地窖本身是甕的形狀，從窄窄的甕口走下去。

每張地圖有兩張提示紙條和一張「記憶」（舊照片），五個夢裡都找得到奶奶的拐杖。

## 部署到 GitHub Pages

不需要建置步驟，原始檔就能直接執行。

1. 建立新的 repository，把這個資料夾的內容全部推上去（包含 `.nojekyll`）。
2. 到 repository 的 **Settings → Pages**。
3. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一分鐘後，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

本機測試時，因為使用 ES Module，不能直接雙擊 `index.html`，要開一個本機伺服器：

```bash
python3 -m http.server 8000
# 然後打開 http://localhost:8000
```

想要單一檔案版本（可直接雙擊開啟或傳給別人），執行：

```bash
node tools/build-single.mjs   # 產生 dist/nightmare-doors.html
```

## 道具效果怎麼判定

每個道具有標籤（`tags`），每個故事有三組標籤：

```js
tags: {
  weak:     ['sound', 'smoke'],  // 有效：怪物逃開
  immune:   ['salt', 'holy'],    // 無效：沒有反應
  provoked: ['light'],           // 反效果：怪物暴怒
}
```

判定順序是 **反效果 → 無效 → 有效**，都沒對到就算無效。所以新增道具時，只要給它標籤，所有舊故事會自動判斷效果。

抽道具時，程式會保證三樣中至少有一樣對其中一扇門有效。

## 新增一個恐怖故事

1. 複製任一個故事資料夾，例如 `src/content/stories/moth-to-flame/`。
2. 修改 `story.js`：成語、門的暗示、弱點標籤、開場字幕、地圖、目標物、紙條、怪物、結局、記憶碎片。
   - `objective.kind`：目標物外觀，可用 `window`、`cup`、`key`、`candle`、`jar`
   - `monster.behavior`：怪物行為，可用 `moth`、`stillness`、`blind`、`trail`、`urn`
   - `theme.floor`／`theme.obstacle`：地板與障礙物的樣式
3. 在 `src/content/stories/index.js` 加一行 import，並放進 `STORIES`。

想做新的怪物行為，在 `world/monsters.js` 新增一個物件並加進 `BEHAVIORS`。

## 讓人想再玩一次的設計

| 設計 | 心理學原理 | 在遊戲裡的樣子 |
|---|---|---|
| 成語門匾＋一句暗示 | 好奇心缺口：知道一點但不知道全部，最想知道答案 | 只看得到「杯弓蛇影」和「門後傳來杯子輕碰的聲音」 |
| 三選一道具 | 稟賦效應：自己選的東西會更在意它的結果 | 「你手上握著……」，結算時標出「你帶的」 |
| 隨機抽門與道具 | 變動比率增強：不知道下一次會抽到什麼，最容易讓人一直玩 | 每局三扇門、三樣道具都不同，至少一扇是今晚沒看過的 |
| 差一點 | 近乎成功效應：差一點就成功的失敗，比大敗更讓人想重來 | 失敗時顯示「只差一步就醒來了（3/4）」 |
| 如果當初 | 反事實思考：「早知道就……」會驅動下一次嘗試 | 「如果當初帶的是 🎵 口琴……」 |
| 今晚的夢與記憶碎片 | 蔡格尼克效應：沒完成的事會一直掛在心上；收集欲 | 「？？？？」格子、「記憶碎片 2／5」、五場都醒來才有隱藏結局 |
| 緊張與釋放 | 恐懼後的解脫感帶來快感；峰終定律：最後的感受決定整體印象 | 目標越少怪物越快，最後一個目標最緊張，醒來時畫面轉白並給出帶轉折的結局 |
| 一鍵再睡 | 降低重來的阻力 | 結算畫面只有一個大按鈕「再睡一次」 |

「今晚的夢」只存在記憶體裡，重新整理頁面就會清空，所以仍然符合「每次重新開局、無存檔」。

## 不存檔的設計

所有狀態都放在 `run.js` 的記憶體裡，沒有使用 localStorage 或 Cookie。結算畫面會顯示「夢的編號」（seed），之後可以加上「輸入編號重做同一場夢」的功能。
